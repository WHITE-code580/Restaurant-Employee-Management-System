"Restaurant Employee Management System"

Description:

A JavaScript OOP project that manages restaurant employees, including managers, waiters, and chefs.
The application uses inheritance, getters/setters, static methods, and role-specific functionality to organize employee
data.

Features: 

•	Manage restaurant employees

•	Track nomination countdown days

•	Store manager nominations

•	Track waiter tips

•	Record chef-prepared dishes

•	Demonstrate OOP concepts such as classes, inheritance, and encapsulation


Concepts Demonstrated:

•	Classes 

•	Inheritance 

•	Getters & Setters 

•	Static Methods 

•	Encapsulation
